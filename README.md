# Integral

Interactive 2D / 3D integral visualizer for your local computer.

## Run on this computer

**Easiest:** double-click `Start Integral.bat`

That installs dependencies if needed, opens your browser, and starts the app at http://localhost:5173/

Or from a terminal in this folder:

```bash
npm install
npm run dev
```

Requires [Node.js](https://nodejs.org) (already installed on this machine).

## How to use

- Switch **2D** / **3D** in the top right.
- Type any expression in the equation bar (`x` in 2D; `x` and `y` in 3D).
- **2D:** drag the coral handles to set bounds, drag empty space to pan, scroll to zoom.
- **3D:** drag the coral corner points to set the domain, then orbit / pan / zoom the view.
